# Catálogo de Filmes

## Descrição

Sistema desenvolvido em Java para gerenciamento de filmes.

O sistema permite:

- Cadastrar filmes;
- Pesquisar filmes por gênero;
- Remover filmes;
- Salvar os dados em arquivo;
- Recuperar os dados previamente salvos.

## Tecnologias

- Java 11
- Swing (JFrame)
- Serialização de Objetos
- JUnit
